# Личная библиотека Slidebrary

1. Распакуйте архив `Slidebrary-Personal.zip` в удобное место.
2. Не переименовывайте папки первого уровня без необходимости.
3. Разложите материалы по соответствующим разделам.
4. В Slidebrary откройте личный кабинет и выберите корневую папку `Slidebrary Personal`.
5. После полного закрытия PowerPoint папку нужно выбрать повторно.

## Структура

```text
Slidebrary Personal/
├── Презентации/
├── Фотографии/
├── Иллюстрации/
├── Иконки/
├── Логотипы/
└── Шаблоны/
```

Внутри разделов можно создавать любые дополнительные папки. Они станут категориями и фильтрами в add-in.

## Поддерживаемые форматы

- Презентации и шаблоны: `.pptx`.
- Фотографии, иллюстрации, иконки и логотипы: `.jpg`, `.jpeg`, `.png`, `.gif`, `.svg`, `.webp`.

Для превью презентации положите рядом изображение с тем же названием:

```text
Презентации/
├── Отчет.pptx
└── Отчет.png
```

Личные материалы читаются непосредственно с устройства и не отправляются в GitHub или облачное хранилище.
